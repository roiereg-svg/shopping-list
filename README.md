# רשימת הקניות שלנו

רשימת קניות משותפת לזוג: הוספה בכתיבה או בקול, חלוקה אוטומטית לקטגוריות, וסימון מוצרים תוך כדי קנייה.

האתר סטטי לגמרי. הסנכרון בין המכשירים עובר דרך `Firestore` של `Firebase`, וכללי האבטחה נמצאים ב-`firestore.rules`.
הגדרות `Firebase` לא נשמרות בקוד: מזינים אותן פעם אחת במסך הפתיחה, והן עוברות לבן/בת הזוג בתוך קישור השיתוף.
